# Node.js . Домашння робота 1

Навчальний проєкт з Node.js та Express.

## Реалізовано

- Express-сервер з використанням змінних оточення
- Middleware: `cors`, `express.json()`
- Логування HTTP-запитів (`pino-http`)
- Обробка неіснуючих маршрутів (404)
- Централізована обробка помилок (500)

## Маршрути

- `GET /notes`
  Повертає повідомлення про отримання всіх нотаток

- `GET /notes/:noteId`
  Повертає повідомлення з ID нотатки

- `GET /test-error`
  Тестовий маршрут для перевірки обробки помилок
