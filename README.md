# Node.js . Домашння робота 4

Навчальний проєкт з Node.js та Express з аутентифікацією користувачів.

## Реалізовано

- Реєстрація та логін користувачів
- Хешування паролів (bcrypt)
- Сесії користувачів (access / refresh токени)
- Аутентифікація через cookies
- Захист маршрутів нотаток
- CRUD-операції для нотаток лише для авторизованих користувачів
- MongoDB / Mongoose
- Валідація запитів (celebrate)
- Глобальна обробка помилок
